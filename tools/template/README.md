# 기준 템플릿 준비

이 폴더의 스크립트는 로컬 원본을 직접 수정하지 않고, 배포용 한 페이지 빈 HWP를 만든다.

1. 원본 HWP를 임시 폴더에 복사한다.
2. 한컴오피스에서 두 번째 신청서 페이지를 삭제한다.
3. 모든 신청자·출장·운임·서명 값 칸을 빈 문자열로 바꾼다.
4. 결과를 `web/src/assets/templates/travel-expense-template.hwp`로 별도 저장한다.
5. 원본 HWP와 작성요령 HWP는 Git과 Vercel 배포물에 포함하지 않는다.

스크립트 출력에는 신청서 값이 포함되지 않고 표 수, 셀 수, 파일 크기만 표시된다.
